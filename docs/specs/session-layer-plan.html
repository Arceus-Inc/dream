Arceus · dream + chorus

Session layer plan

Close the Level-1 session gaps versus Hermes and Paperclip: durable conversation + tool-call history, save/resume, and tool-call secret proxies. Middleware is mostly covered by dream hooks already.

1. Definitions

Conversation history

Typed message list the model re-reads: user / assistant / tool_result atoms.

Tool-call history

Queryable records of each invocation: id, name, args, result, error, timing.

Tool-call middleware

Rewrite args before policy, or wrap execution (next_call). Distinct from observer hooks.

Save & resume

Persist harness+convo state; continue after process death without re-orientation.

Secret proxies

Model sees placeholders only; trusted runtime resolves at egress and redacts returns.

3. Build order (TDD + eval each step)

PR1 — Durable SessionStore

gap File-backed snapshot under sessions_dir.

  • SessionSnapshot + ToolCallRecord (typed JsonValue inputs)
  • FileSessionStore.save/load (atomic)
  • Session.snapshot / restore_from_snapshot
  • Harness.save_session / resume_session
  • Eval: roundtrip transcript + cost; no dangling tool_use

PR2 — Append-only tool-call history

partial Durable index beside the snapshot.

  • tool_calls.jsonl written from dispatcher observer
  • Backfill from transcript on save
  • Eval: N tool calls → N durable records with matching ids

PR3 — SecretProxy runtime

gap Placeholder → resolve-at-dispatch → redact-on-result.

  • Align with CredentialBrokerPort when merged
  • Wire into EngineToolDispatcher
  • Eval: raw secret never appears in saved transcript / events content

PR4 (defer) — Formal middleware kinds

have Hooks already rewrite args/results. Defer Hermes-style nested tool_execution(next_call) and llm_request until a consumer needs wrap semantics.

4. Chorus boundary

Chorus keeps work continuity (ledger, TODO.md, cross-beat resume skills). Dream must own conversation continuity. Chorus should call harness.save_session at beat end and resume_session when a role re-enters the same task thread — without stuffing secrets into briefs.
